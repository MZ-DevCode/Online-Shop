# 🛒 Online-Shop (Веб-приложение на Go)

Легковесное и многофункциональное веб-приложение интернет-магазина, написанное на чистом Go (без тяжелых веб-фреймворков). Проект включает в себя систему аутентификации, каталог товаров, корзину, оформление заказа и интеграцию с Telegram-ботом.

---

## 🚀 Основные возможности
* **Аутентификация:** Безопасная регистрация, вход в систему и управление профилем пользователя.
* **Каталог и товары:** Просмотр и добавление товаров.
* **Корзина и оформление:** Добавление товаров в корзину и процесс чекаута.
* **Telegram-бот:** Встроенный модуль для уведомлений и управления через бота. 
* **API Документация:** Автоматически сгенерированная документация Swagger.
* **Контейнеризация:** Готовый `Dockerfile` для быстрого деплоя.

## 🛠 Технологии
* **Бэкенд:** Go 
* **База данных:** SQLite
* **Документация:** Swagger 
* **Контейнеры:** Docker
